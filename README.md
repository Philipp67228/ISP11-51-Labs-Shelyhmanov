## Постановка задачи
Консольное приложение для изучения иностранных слов. Пользователь добавляет пары «слово — перевод», ищет и удаляет их, а также проходит тренировку с проверкой перевода. Данные сохраняются в файл и доступны при следующем запуске.

## Язык и запуск
Python 3.9+ (проверено на 3.13), сторонние библиотеки не нужны.

```bash
cd lab-3-slovar
python src/main.py
```

## Формат файла данных
`data/words.json` — JSON-объект, где ключ — слово, значение — перевод:
```json
{
  "apple": "яблоко",
  "book": "книга"
}
```
Слова хранятся в нижнем регистре. Если файла нет, программа стартует с пустым словарём.

## Используемые коллекции
- **dict** `{слово: перевод}` — основное хранилище. Поиск, добавление и удаление по ключу выполняются за O(1), а повторяющиеся слова невозможны.
- **list** — случайный набор вопросов для тренировки (`random.sample`) и результаты поиска.
- **set** — слова, в которых пользователь ошибся на тренировке (без дублей).

## Возможные ошибки и их обработка
| Ситуация | Реакция программы |
|---|---|
| Файла данных нет | Старт с пустым словарём, файл создаётся при первом сохранении |
| Файл повреждён (невалидный JSON) | Сообщение, копия в `words.json.bak`, старт с пустым словарём |
| Пустое слово или перевод | Сообщение, запись не добавляется |
| Не число в тренировке / число вне диапазона | Повторный запрос ввода |
| Несуществующий пункт меню | Сообщение «Нет такого пункта меню» |
| Удаление отсутствующего слова | Сообщение «Такого слова нет» |
| Ошибка записи файла | Сообщение об ошибке, программа не падает |
| Ctrl+C / Ctrl+D | Корректный выход с сохранением |
